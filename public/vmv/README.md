# Imágenes de VMV Call

Sube aquí el archivo **imagen-1.webp** (WebP con fondo transparente).

La tarjeta principal en Inicio ya busca automáticamente `/vmv/imagen-1.webp` y muestra «Imagen 1» si aún no existe.

No cambies el nombre, las minúsculas ni la extensión.

El material original puede guardarse fuera de esta carpeta; la app sirve exclusivamente la copia WebP optimizada.
